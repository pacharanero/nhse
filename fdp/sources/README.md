# Source documents

This directory retains primary documents and local archive fallbacks used by the FDP timeline. Timeline entries continue to cite the canonical public source and an independent archive where one exists; repository copies protect the evidence base if those routes disappear.

Companion Markdown notes record provenance, original filenames, hashes, evidential limitations and the passages relied on. Retained binaries use stable slug-case names so links do not depend on supplier or download-system naming.

Repository-authored Markdown notes are covered by the project's CC-BY-SA-4.0 prose licence except for attributed quotations. Binary PDFs and Word documents are third-party source material and are not covered by the project's software or prose licences. Copyright and other rights remain with their original owners; retaining a copy here does not relicense the document.
