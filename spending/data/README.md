# Published spending data

This directory contains normalized, immutable spending-data releases generated by `nhse_spending.py`. Do not hand-edit generated artifacts; fetch the registered source, run `s/build-spending-data`, inspect the validation and checksum changes, and commit the complete release directory.

## Releases

The D11 historical backfill (2026) covers fiscal year 2013/14 and every calendar year 2014-2023 using the D6 census's catalogued sources, bringing total payments coverage to 809,371 rows and £311.631bn across 2013/14-2024, plus September 2025. Each release below is independently fetched, built and validated against its own registered digests; none depends on another release's bytes.

- `2013-14-payments-over-25000/` - the single combined fiscal-year 2013/14 workbook, 140,907 rows. The source carries no VAT registration number column (replaced by a "Comments from NHS England" column, not captured as a structured field); the four published quarterly CSVs cover the same underlying data in a different format and are not separately ingested, confirmed by matching transaction numbers, amounts and dates against the combined workbook.
- `2014-payments-over-25000/` - April-December 2014 only; January-March 2014 are not published anywhere in the discovered corpus, recorded as missing rather than zero. November 2014 carries a stray trailing reference-code column beyond the 10 registered fields.
- `2015-payments-over-25000/` through `2017-payments-over-25000/` - all twelve monthly workbooks each year, no anomalies.
- `2018-payments-over-25000/` - all twelve 2018 monthly workbooks; February 2018 (itself a "revised" republication, like March 2018) contains 138 rows with the literal number `0` in the Expense Area column instead of the usual text, parsed as the digit's own text rather than rejected or guessed at.
- `2019-payments-over-25000/` - all twelve 2019 monthly workbooks; May 2019 is published without a Transaction number column at all; February 2019 contains five rows where a pasted internal document-server URL corrupted the AP Amount and subsequent columns, excluded with a recorded reason and transparently counted in validation rather than silently dropped.
- `2020-payments-over-25000/` - all twelve 2020 monthly workbooks; June 2020 contains one row with a non-integral decimal value in the Purchase invoice number column, preserved as published rather than rejected.
- `2021-payments-over-25000/` - all twelve monthly workbooks, no anomalies.
- `2022-payments-over-25000/` - all twelve monthly workbooks; January 2022 carries stray single-character marker cells in seven trailing columns beyond the registered ten, the same shape as November 2014's trailing-column case.
- `2023-payments-over-25000/` - all twelve 2023 monthly workbooks, 50,915 rows. First release of the D11 historical backfill; no superseded revision exists for 2023.
- `2024-payments-over-25000/` - all twelve current 2024 monthly workbooks, 51,971 rows and a deterministic diff between the superseded and corrected July publications. The original “July” file repeated June-dated rows apart from VAT identifiers; the corrected file replaces the whole month.
- `2025-09-payments-over-25000/` - NHS England payments over £25,000 for September 2025, including all five published entities. The project owner approved redistribution of this normalized release on 17 October 2026 under the rights basis recorded in `../data-sources.yaml`. The raw workbook is not committed.
- `procurement-notice-fixtures-2026-10-17/` - bounded Find a Tender and Contracts Finder enrichment fixtures with typed procurement values, notice relationships and review-only payment-supplier candidates. The observation date is part of the immutable release identity; procurement values are never represented as payments.
- `2013-14-nhsd-spend-information/` through `2022-23-nhsd-spend-information/` - NHS Digital's (formerly HSCIC's) own pre-merger spend-information series, D13, registered in `../nhsd-data-sources.yaml` and built by `nhse_nhsd_spending.py`, not `nhse_spending.py`. Ten fiscal years, 15,758 rows, £2,686,446,283.22. A legally and editorially separate corpus from the NHS England releases above - different publisher, different column schema (`nhsd-spend.parquet`/`nhsd-spend.csv.gz`, no transaction number or VAT fields, has a free-text `description` field), never summed into NHS England's totals. See "NHS Digital / HSCIC spend information (pre-merger)" in `../../spec/spending-data.md` for the schema, the one preserved 2019/20 date anomaly, and the open TPP-absence finding.

Each release carries a Data Package descriptor, exact SHA-256 checksums and machine-readable reconciliation results. `payments.parquet` is canonical; `payments.csv.gz` is the deterministic compatibility export. Every revision marker the D6 census flagged before 2024 (December 2014, all of 2015, January-September 2016, February and March 2018) is published as discovered — the current republished file only, without an independently recovered superseded original or row-level diff; only July 2024's correction has that fuller treatment, per `spec/spending-data.md`.
